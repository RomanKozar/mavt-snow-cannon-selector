## Метод MAVT

**Multi-Attribute Value Theory** — метод багатокритеріального аналізу, що агрегує часткові ціннісні функції в єдиний показник.

### Формула агрегації

```
V(a) = Σ wᵢ · vᵢ(xᵢ)
```

| Символ   | Значення                                  |
| -------- | ----------------------------------------- |
| `V(a)`   | Агрегований показник альтернативи `a`     |
| `wᵢ`     | Вага `i`-го критерію, де `Σwᵢ = 1`        |
| `vᵢ(xᵢ)` | Нормалізована ціннісна функція `∈ [0, 1]` |

### Ціннісна функція (лінійна нормалізація)

```
Максимізація:  vᵢ(x) = (x − xᵢ_min) / (xᵢ_max − xᵢ_min)
Мінімізація:   vᵢ(x) = 1 − (x − xᵢ_min) / (xᵢ_max − xᵢ_min)
```

### Кроки алгоритму

1. Визначити множину альтернатив та критеріїв
2. Встановити діапазони `[min, max]` і напрям кожного критерію
3. Нормалізувати значення через ціннісну функцію
4. Призначити ваги `wᵢ` критеріям
5. Обчислити `V(a)` для кожної альтернативи
6. Ранжувати за спаданням — найбільше `V(a)` є оптимальним

## Структура програми

```
index.html
│
├── <style>          # CSS-змінні, темно-синя тема, адаптивна сітка
│
├── <canvas>         # Анімований снігопад (HTML5 Canvas API)
│
├── UI / Кроки
│   ├── Крок 1       # Введення альтернатив (гармат)
│   ├── Крок 2       # Налаштування критеріїв
│   ├── Крок 3       # Призначення ваг (слайдери)
│   └── Крок 4       # Відображення результатів
│
└── <script>
    ├── State        # alternatives[], criteria[], weights[]
    ├── Rendering    # renderAlternatives / renderCriteria / renderWeights / renderResults
    ├── MAVT Core    # valueFunction(x, crit) · computeMAVT()
    └── Snow         # requestAnimationFrame canvas loop
```

### Потік даних

```
[alternatives[]]  ──►  [criteria[]]  ──►  [weights[]]
                                               │
                                    computeMAVT()
                                               │
                              valueFunction(x, crit) × wᵢ
                                               │
                              sort by V(a) DESC  ──►  renderResults()
```

## Інструкція користувача

### Крок 1 — Альтернативи

Введіть назви та характеристики снігових гармат.  
Кнопка **«＋ Додати гармату»** — додає нову альтернативу.  
Кнопка **«✕ Видалити»** — видаляє рядок.  
Кнопка **«⟳ Скинути»** — повертає дані за замовчуванням.

### Крок 2 — Критерії

Налаштуйте параметри оцінювання:

- **Назва** критерію
- **Min / Max** — діапазон для нормалізації
- **Напрям**: Максимізація ↑ або Мінімізація ↓

### Крок 3 — Ваги

Перетягуйте слайдери для встановлення важливості критеріїв.  
Відсоток оновлюється в реальному часі.  
Ваги автоматично нормалізуються при розрахунку.

### Крок 4 — Результати

Після натискання **«🔍 Розрахувати MAVT»** відображається:

- 🏆 Блок переможця з агрегованим показником
- 📊 Таблиця рейтингу всіх альтернатив
- 📈 Барчарт порівняння
- 🃏 Картки часткових ціннісних функцій по критеріях

## Висновок

У ході роботи реалізовано повний цикл методу MAVT для задачі вибору оптимальної снігової гармати.

**Результат** при вагах за замовчуванням — переможець **Bächler Xeno T40**: найвища продуктивність (1680 м³/год), найменше енергоспоживання (14 кВт) та найбільша дальність (65 м) забезпечують їй найвищий агрегований показник.

**Переваги MAVT:**

- Прозорість та відтворюваність результатів
- Простота інтерпретації: `V(a) ∈ [0, 1]`
- Можливість аналізу чутливості через зміну ваг

**Обмеження:** метод передбачає незалежність критеріїв (адитивна сепарабельність). При сильній кореляції між критеріями рекомендується AHP або MAVT з мультиплікативною агрегацією.
